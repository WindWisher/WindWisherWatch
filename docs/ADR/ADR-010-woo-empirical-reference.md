# ADR-010: Woo as an empirical comparison reference

- Status: Accepted
- Context: Real-session comparison is valuable, but Woo outputs are algorithmic and not physical ground truth.
- Decision: Build a versioned, consented comparison framework reporting event detection and metric errors against Woo as a reference with stated uncertainty.
- Alternatives considered: Treat Woo as truth; laboratory-only validation; anecdotal manual checks.
- Consequences: Practical field evidence without overstated claims.
- Risks: Clock alignment, proprietary semantics, cohort bias, licensing/privacy.
- Follow-up: Establish rights, consent, matching tolerance, splits, and independent references in M5.
