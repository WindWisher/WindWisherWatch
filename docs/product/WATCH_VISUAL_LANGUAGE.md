# WindWisherWatch visual language

Future WindWisherWatch UI equals WindWisher brand identity plus wearable-native adaptation.

The WindWisher mobile application is the identity reference for palette, hierarchy, tone, iconography and reusable brand assets. Before productive UI work, the real main application must be inspected and exact tokens extracted; M3 does not invent or hardcode a separate Garmin aesthetic.

Layouts must adapt rather than copy mobile screens. Glanceability, sunlight readability, physical controls, motion, water/gloves, high contrast, large critical values, non-color-only status, display technology, color depth, burn-in and battery constraints take precedence. Garmin, watchOS and Wear OS should share product identity while retaining native platform adaptation.

The current Session Engine screen is a developer harness only. It is not evidence of final product design.
